# 📱 Samsung-Style Calculator Android App

Clean, responsive Samsung One UI inspired calculator with History, Unit Converter, and Scientific Mode.

---

## 📥 Direct APK Download

Once GitHub Actions finishes building, you can download the APK directly:
1. **GitHub Releases (One-Click APK Download):** Go to [Releases](../../releases) and download **`Calculator-App.apk`**.
2. **GitHub Actions Artifacts:** Go to [Actions](../../actions) ➔ Click the latest workflow run ➔ Scroll down to **Artifacts** ➔ Click **`Calculator-App`**.

---

## 🚀 How to Build & Download APK on GitHub (સ્ટેપ બાય સ્ટેપ)

1. **GitHub Actions** આ રિપોઝીટરીમાં પહેલેથી સેટ કરેલું છે.
2. કોઈપણ ફેરફાર પુશ (Push) કરો અથવા [Actions](../../actions) ટેબમાં જઈને **"Run workflow"** પર ક્લિક કરો.
3. ૧ થી ૨ મિનિટમાં GitHub આપોઆપ Android APK તૈયાર કરી દેશે.
4. [Releases](../../releases) સેક્શનમાંથી સીધી **Calculator-App.apk** ફાઇલ ડાઉનલોડ કરીને તમારા એન્ડ્રોઇડ ફોનમાં ઇન્સ્ટોલ કરી લો!
